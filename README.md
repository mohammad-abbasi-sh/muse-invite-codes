Free Muse tokens with an invite code. New users can redeem this code
within the first 48 hours after joining Muse.

## How to redeem

- **Mobile (iPhone / Android):** open the Muse app → **Settings → Redeem token**.
  Available only during the first 48 hours after joining.
- **Web (muse.ai):** **Settings → General → Usage → Redeem invite code**.

## What to know (honest notes)

- Each account can redeem **one code only** (`already_redeemed` after that).
- Each code works **up to 30 times** (`used_up` after that) — per the
  [muse-protocol](https://github.com/duwqijlk/muse-protocol) research.
- The exact reward is shown on the redemption screen; this page promises no
  specific number of tokens.
- Seeing an Invite button does not mean the account can redeem a code —
  sharing and redemption are separate.

## What is muse-protocol?

[muse-protocol](https://github.com/duwqijlk/muse-protocol) is an open-source
research project documenting the HTTP protocol behind muse.ai registration
and invite-code redemption (OTP flow, session bootstrap, TOS acceptance,
`vm/wake`, and the redeem endpoint). The redemption statuses above
(`redeemed` / `already_redeemed` / `used_up` / `invalid`) come from its
documentation. Credit to the author, duwqijlk.
