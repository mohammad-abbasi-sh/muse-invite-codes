# کد دعوت Muse — توکن رایگان

**صفحهٔ زنده:** https://mohammad-abbasi-sh.github.io/muse-invite-codes/

اگه تازه به موس (Meta Muse) پیوستی، یکی از کدهای زیر رو در ۴۸ ساعت اول ثبت‌نام
وارد کن و توکن رایگان بگیر.

## کدها

| کد | توضیح |
|------|------|
| **ZV55CE** | اول این رو امتحان کن |
| **3UILU4** | اگه اولی پر شده بود، این رو بزن |

## چطور وارد کنم؟

- **موبایل (آیفون و اندروید):** اپ Muse ← ‏**Settings ← Redeem token** — فقط ۴۸ ساعت اول بعد از عضویت.
- **وب (muse.ai):** ‏**Settings ← General ← Usage ← Redeem invite code**.

## نکته‌های صادقانه

- هر حساب فقط **یک بار** می‌تونه کد وارد کنه.
- هر کد حداکثر **۳۰ بار** قابل استفاده‌ست (طبق مستندات پروژهٔ
  [muse-protocol](https://github.com/duwqijlk/muse-protocol)). اگه کد اول پر شده بود، کد دوم رو امتحان کن.
- مقدار دقیق پاداش روی صفحهٔ ورود کد نشون داده می‌شه؛ این صفحه عدد مشخصی قول نمی‌ده.

## muse-protocol چیه؟

[muse-protocol](https://github.com/duwqijlk/muse-protocol) یه پروژهٔ تحقیقاتی متن‌بازه
که پروتکل HTTP ثبت‌نام و ورود کد دعوت muse.ai رو قدم‌به‌قدم مستند کرده.
وضعیت‌های ورود کد (redeemed / already_redeemed / used_up / invalid) از مستندات همون پروژه‌ست.
